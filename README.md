# Simple Report Aggregator

将同一轮测评的子报告整理成一份精炼的综合测评报告，同时生成一份供内部留存的支撑材料。按本轮子报告识别测评对象和维度。

## 安装

> 请安装 GitHub 仓库 Ma-Ruinan/Simple-Report-Aggregator 的 main 分支下的 simple-report-aggregator Skill。安装地址是 https://github.com/Ma-Ruinan/Simple-Report-Aggregator/tree/main/simple-report-aggregator。

## 使用

附上本轮子报告，或提供文件路径。Excel 测试记录通常用于生成子报告，汇总时无需另附。若已提供，可按需要适度参考。

> 请使用 $simple-report-aggregator，把我附上的本轮子报告汇总成综合测评报告。对象 A 是产品甲，B 是产品乙。请保留能解释差异的图表，必要时用可核对的数据重绘。交付一份对外报告和一份内部支撑材料，均为 Word 文件。

| 文件 | 用途 |
| --- | --- |
| 综合测评报告 | 用于对外发送，呈现测评范围、主要观察、分项结果与综合结论。 |
| 综合测评支撑材料 | 用于内部留存，包含来源定位、逐题或逐次明细、图表数据和复核记录。 |
