# 结构与图表

## 对外报告

| 位置 | 内容 |
| --- | --- |
| 封面与目录 | 题名、对象、范围和必要日期。按篇幅提供目录，页码与成稿一致。 |
| 测评总览与执行摘要 | 首次使用简称时写明对象映射，例如「A（产品甲），B（产品乙）」。用总览表展示核心指标和必要样本量，再写「主要观察」。 |
| 分项测评结果 | 按本轮维度展开。先给结果，再用有解释力的图表、代表性案例或反例说明差异。 |
| 执行消耗 | 有可比运行数据时呈现。例如用时、Token、调用数。单次请求和整项任务的耗时分别展示。 |
| 综合结论 | 归纳实际测评中的主要差异与取舍。样本或条件会影响解释时，在相关结论旁简明交代。 |

## 图表的取舍与调整

1. **直接采用。** 原图指标清楚、数据与正文吻合、对象顺序和图例可读时保留原图。删除重复的呈现，保留能说明分布、反例和差距来源的图。
2. **适度整理。** 如原图仅在样式上不统一，可调整字体、配色、图例、标注或裁去无关边距。只在同一指标定义、单位和可比范围下合并同类图。保留原始数据、合理坐标尺度和必要标签。
3. **按数据重绘或补图。** 原图缺失、存在错误、信息过密，或不适合直接复用时，优先用已核对的汇总表或锁定值重绘。需要展示过程时，可从对应 Excel 提取测试结果或记录，生成必要的状态、耗时、重试或配对比较图。每张图解决一个具体阅读问题。没有可靠数据时可用表格或简短文字。

Excel 表头可能跨行，含合并单元格，对象名称也可能藏在列标题中。用任务标识、对象和必要时的运行轮次对齐，检查重复、空值、混合格式时长和重试记录。首次运行与最终交付分别统计。比较同题成功耗时时，先选定同一纳入口径，区分首次成功与重试成功，记录有效配对数。不要把失败、仍在运行或缺失时长当作零。

以虚构数据为例，「2m30s」和「3 分 15 秒」可以统一换算为 150 秒和 195 秒，再对双方均有有效成功时长的任务画配对点图。如果一方只记录失败后的尝试时长，保留该状态及对应记录，按既定规则排除该任务的成功耗时配对。交付质量仍用正式评分结果。

## 内部支撑材料

保留文件名及定位、实际采用的对象映射、逐题与逐次结果、图表对照、口径与冲突处理。对重绘图附底表或可定位的原始数据、筛选范围、换算与汇总规则。记录对外数字和结论的复核情况，以及哪些值因缺少明细只能按正式来源引用。内部材料篇幅按追溯需要决定。
