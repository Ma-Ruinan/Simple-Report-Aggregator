# Word 标题字体与渲染

封面 Title、Heading 1、Heading 2、Heading 3 及实际使用的更深层级采用一致的中文字体与协调的拉丁字体。选择目标环境可用的字体，例如中文「微软雅黑」和西文 Arial。用字号、字重、留白区分层级。目录、标题里的数字编号、英文术语和中英混排也按相同体系检查。

## 避免字体被主题覆盖

仅设置西文字体，或只添加 `w:eastAsia`，不足以统一 Word 标题。内置标题样式可能仍保留 `w:asciiTheme`、`w:hAnsiTheme`、`w:eastAsiaTheme`、`w:cstheme`。模板的主题字体、字符样式和直接格式也会影响最终字形。

- 生成时对实际使用的标题样式显式指定 `w:rFonts` 的 `w:ascii`、`w:hAnsi`、`w:eastAsia`、`w:cs`，同时清掉这些样式中冲突的主题字体属性。使用 python-docx 时，`style.font.name` 主要设置西文字体，仍应检查和修改 `rFonts` 的东亚和主题属性。
- 逐项检查继承样式、字符样式、文本 run 的直接格式及自动编号的字体。只修正会覆盖标题字体的设置，保留标题层级和有意的强调。若同时设置 `w:sz`、`w:szCs`，保持同一层级的字号一致。
- 可解包查看 `word/styles.xml`、`word/document.xml`，以及自动编号使用的 `word/numbering.xml`。采用模板时也检查主题中的东亚字体。显式指定的字体在交付环境中应可用。

## 渲染检查

渲染最终 DOCX，优先用 Word 或与交付环境相近的渲染器。逐页查看封面和所有实际使用的标题层级，对照中文、西文、数字和编号的字形、粗细及对齐。发现回退、混用或异常字距时，修正样式并重新渲染，再核对页码和目录。XML 检查和视觉检查分别执行。
